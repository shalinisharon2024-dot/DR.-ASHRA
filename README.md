# 🩺 Dr. ASHRA — Smart Health Portal
> *"Healthy body, Happy soul"*

**Dr. ASHRA** is an interactive healthcare web app designed for personalized health monitoring and instant AI assistance.

### ✨ Key Features
- **Emerald Welcome Screen**: 5-second splash backdrop with sleek quote.
- **2-Step Registration**: Input validation, phone number checks, and **English / Telugu / Hindi** full-UI toggle.
- **Lavender Login**: Secure authentication flow.
- **Smart Dashboard**:
  - Profile menu with edit/logout options.
  - Hamburger menu for Uploads, Appointments, Medicine Reminders, Daily Nutrition, Health History & **Emergency SOS (108, 112, 102)**.
  - Interactive SVG circular tracking for Height, Weight, Diabetes, Sleep, and **Menstrual Cycle** (Female profiles only).
- **Maya AI Assistant**: Floating animated robot with voice chat (speech-to-text / text-to-speech) and health visual aids.

### 🛠️ Built With
- **Frontend**: HTML5, CSS3, ES6+ JavaScript, FontAwesome, SVG
- **Speech**: Web Speech API
- **Backend Ready**: Compatible with Supabase / Node.js + MySQL
